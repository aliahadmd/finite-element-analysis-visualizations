p-Refinement
Section 5 · Increasing polynomial degree for improved approximation
Description

p-refinement increases the polynomial degree (p) of shape functions within elements to improve accuracy without changing mesh size.

Higher p values add internal nodes and enable better approximation of complex functions within each element.
