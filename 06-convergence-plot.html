Mesh Convergence Study
Section 6 · Error vs. mesh size on log-log scale
Description

Mesh convergence shows how the numerical error decreases as the mesh is refined. On a log-log plot, the slope indicates the convergence rate.

The theoretical rate depends on element type and polynomial order. Linear elements typically show O(h²) convergence.
